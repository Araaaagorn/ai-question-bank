# 功能清单与实现状态

> 用途：为编写《AI+题库智能教学平台详细功能说明书》提供逐项功能盘点依据。
> 分析基线：本工作区（`ai-question-bank-fork`，`main` 分支）当前代码。
> 判定口径：✅ 已实现 / 🟡 部分实现 / ⬜ 未实现 / ❓ 待验证。
> 证据以当前代码为准；文档与代码冲突处一律以代码为判断依据并记录差异。

## 一、系统功能模块总览

| 模块 | 说明 | 总体状态 |
| --- | --- | --- |
| SYS 系统公共 | 健康检查、注册/登录/登出/当前用户、会话管理、静态托管 | ✅ 已实现 |

## 四、尚存问题与待核实事项

1. **题目写操作无所有权隔离**：任意 teacher/admin 可编辑/删除任意题目（`handle_question_update/delete` 无 `teacher_id` 归属校验），与"多租户数据隔离"预期不符。
2. **题目写操作非单事务**：新增/更新为多次 `kv_set`，失败可能留下半写题目。
3. **题目列表不按 status 过滤**：`questions.md` 称"返回全部 active"，代码遍历全部 `qdata` key 不判 status（当前数据全为 active，行为等价）。
4. **导出前端未接入**：后端 `export/export-policy` 已实现且有测试，前端无入口。
5. **审计只写不读**：`ai_access_audit`/`teacher_ai_audit` 有写入，无查询接口/页面。
6. **会话/任务/对话均为内存态**：重启即失效，无持久化（README/文档已自述为 demo 取舍）。
7. **测试未经本次运行验证**：需要在 Linux/WSL 环境执行 `make test` 复核。
