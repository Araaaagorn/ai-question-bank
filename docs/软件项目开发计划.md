## 一、项目概述

### 1.1 项目名称

AI+题库智能教学平台

### 1.2 项目背景

本项目面向高校教育场景，旨在构建一个多教师、多学生、多租户的智能题库与试卷管理平台。当前教育信息化过程中，题库系统普遍缺乏 AI 辅助解题能力，师生协作效率低下，知识沉淀困难。本平台通过集成大模型能力，实现题库管理、试卷组织、AI 智能解答、分支对话树讨论等功能，为教学场景提供完整的数字化解决方案。

### 1.3 项目目标

- 构建支持 C11 技术栈的高性能后端服务
- 实现多租户数据隔离的题库与试卷管理
- 集成大模型（兼容 OpenAI 协议）实现 AI 解题代理
- 提供纯 HTML/CSS/JS 前端，零构建工具链
- 建立规范的 CI/CD 与代码审查机制

### 1.4 项目范围

| 包含 | 不包含 |
|------|--------|
| 用户认证（登录/登出/会话管理） | 第三方 SSO 集成 |
| 题库 CRUD + 试卷管理 | 商业化支付系统 |
| AI 代理调用（API Key 不出后端） | 多语言国际化 |
| 分支对话树讨论 | 移动端原生 App |
| 管理后台与审计日志 | 视频/音频题目 |

## 五、风险管理

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| C 技术栈学习曲线陡峭 | 高 | 中 | AGENT.md 编码规范 + AI 辅助编码 |
| Windows 无法本地编译 | 高 | 低 | 以 CI 编译结果为准 / WSL2 |
| 大模型 API 调用不稳定 | 中 | 高 | 重试机制 + 失败降级 |
| 多人并行开发代码冲突 | 中 | 低 | 功能分支 + PR 审查 + CI 卡点 |
| 时间不足未完成全部功能 | 中 | 高 | MVP 优先级分级，P2 可砍 |
| Session 内存存储不可扩展 | 低 | 中 | Demo 阶段可接受，P2 评估替换 |
| 前端与后端接口不一致 | 中 | 中 | api.md 先行定义，双方确认 |

## 七、质量保证

### 7.1 编码规范

- C11 标准，`gcc -std=c11 -Wall -Wextra` 零警告
- Conventional Commits 提交信息
- 详情见 `docs/AGENT.md` 和 `CONTRIBUTING.md`

### 7.2 测试策略

| 层级 | 负责 | 内容 |
|------|------|------|
| 单元测试 | 各开发者 | C 函数级测试 |
| API 测试 | 卢恒毅 | 冒烟测试 case_*.sh |
| 集成测试 | 全员 | 全链路手动走查 |
| CI 自动测试 | GitHub Actions | 每次 push/PR 自动运行 |

### 7.3 代码审查

- 每个 PR 至少 1 人 Approve
- Reviewer 检查清单见 `CONTRIBUTING.md`
- 安全红线见 `docs/AGENT.md` 第 6 章
